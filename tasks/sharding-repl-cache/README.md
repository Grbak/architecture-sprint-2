# Шардирование, репликация и кэширование

## Запуск контейнеров

Запускаем контейнеры:

```
docker compose up -d
```

## Дальнейшая настройка

Поскольку добавляемый в текущем задании сервис Redis не требует никаких явных дополнительных настроек, весь процесс настройки в текущем задании полностью совпадает с процессом, описанным в задании _mongo-sharding-repl_.

## Проверка результатов

Проверить результат добавления кэширования можно отправив с помощью Postman GET-запрос на адрес http://localhost:8080/helloDoc/users и оценив время его выполнения.
